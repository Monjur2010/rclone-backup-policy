# rclone Drive Backup

This is a personal, single user tool. It uses rclone to copy files from my own computer into my own Google Drive account, so that I have an off machine backup of my own work.

## What it does

- Copies files one way, from my computer to my Google Drive.
- Never deletes anything on Google Drive.
- Runs on a schedule on my own machine.

## Who uses it

Only me. There is no sign up, there are no other users, and no service is offered to anyone else.
